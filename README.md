# 🌸 Madam Ji — Birthday Celebration Web Experience

A romantic, interactive birthday celebration web application built with React, Vite, Tailwind CSS, and GSAP.

---

## ✨ Features

- **🌸 Grand Landing Page & Countdown:**
  - Live animated countdown to the special celebration day.
  - Cycling romantic quotes and high-contrast typography.
  - Polaroid preview deck with botanical decorations and washi tape.

- **📖 Interactive Scrapbook & Memory Chapters:**
  - 4 curated memory chapters with romantic handwritten notes.
  - Interactive Polaroid cards that tilt, zoom, and open into high-resolution modals with heartfelt personal messages.
  - Cinematic widescreen video player with romantic styling.

- **🎂 3-Stage Birthday Celebration Stage:**
  - **Stage 1:** Make a wish & blow out animated candles (interactive tap or button trigger).
  - **Stage 2:** Interactive knife dragging to slice the birthday cake.
  - **Stage 3:** Confetti cannon burst, romantic music-box theme, and an authentic deckle-edge wax-sealed parchment love letter.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP (GreenSock Animation Platform) + Custom Web Audio API
- **Routing:** React Router v7
- **Smooth Scrolling:** Lenis

---

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   cd madam-ji
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
